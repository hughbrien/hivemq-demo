# hivemq-demo
Create an Agentic Agent that manages multiple IOT devices. 

Use the example of airport security : 

There multiple simulated devices : 

Gates.  There are 10 entry points.  5 Pedenstrian Gates and  5 Vehicle Gates 
Motion Detectors : there are 10 motion detector 

Agent should monitor all the devices and send Events to the HiveMQ
The Events are Security Events 



Use the HiveMindMQ Platform to enable the devices to communicate.
